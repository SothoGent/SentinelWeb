# SENTINEL MESH // Web Deployment

Cinematic demonstration of the SENTINEL Mesh concept.
Built for Enovate4Impact 2026, Stream 1.

## Structure
- `videos/` rendered scenes ready for web playback
- `images/` satellite imagery and HUD assets
- `python/` source scripts and render pipeline
- `src/` HTML, CSS, JS for the player interface

## Deploy
Push to GitHub and connect to Vercel. Static output served from root.
